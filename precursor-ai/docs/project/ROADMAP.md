# Roadmap (original 10 phases, unchanged)

Canonical for the planned sequence. Do not rename, merge, reorder or remove phases without explicit user authorization. Current status per phase: [PROJECT_STATUS.md](PROJECT_STATUS.md). Details: `docs/phases/PHASE_NN.md`.

**ML policy:** actual ML/DL development is deferred to a separately authorized phase after this roadmap is complete and reviewed. Until then every model is a placeholder ([scientific-integrity.md](../../.claude/rules/scientific-integrity.md)). Phases 7-8 therefore deliver interfaces, contracts and non-predictive scaffolding only, unless the user authorizes otherwise. Product focus: landslide early prediction (static susceptibility + dynamic trigger). A reserved **ML slot** (Phase 7) is where the user's finished model plugs in later; the frontend may show clearly labelled **MOCK** prediction views behind a default-off flag (Phase 9). See [ADR-0008](../adr/ADR-0008-ml-slot-and-labelled-mock-frontend.md).
