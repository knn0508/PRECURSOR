# ML stage M9: Packaging, model card and handoff

Status: **NOT_STARTED**. Track: [ADR-0009](../../adr/ADR-0009-ml-development-track.md); status table: [ML_STATUS](../ML_STATUS.md). Executable brief: [Prompts.md](../../../Prompts.md) (section M9). Separate from the 10 roadmap phases; roadmap phases stay ML-free.

## Objective
Packaging, model card and handoff. See scope below.

## Scope
- For each kept model: `ml/export/<model_id>/<version>/` laid out for the ADR-0008 ML slot (model files, metadata.json, model_card.md, feature spec via `ModelInputSpec`, training_data_provenance.json, calibration artifacts, explainer config, valid region and time, failure modes, intended and non-intended use, evaluation summary, code version, seed).
- Standalone tested inference function inside `ml/` validating input against `ModelInputSpec` and refusing out-of-region, out-of-time or low-quality input.
- Compatibility gap list against the ML slot contract (Phase 7); Phase 7 is not modified.
- `ml/reports/M9_final.md`: data, methods, results, limitations, biases, one-command reproduction per stage, intended use (research prototype, not an operational warning system).
- Reproducibility test rebuilding a package from the logged config.

## Out of scope
- Integration into backend, frontend or DB, switching `PREDICTION_BACKEND`, mock-to-real switch.
