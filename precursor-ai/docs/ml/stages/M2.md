# ML stage M2: Data acquisition (approved files only)

Status: **COMPLETED** (2026-11-15: every approved item arrived; see ML_STATUS and ml/reports/M2_acquisition.md). Track: [ADR-0009](../../adr/ADR-0009-ml-development-track.md); status table: [ML_STATUS](../ML_STATUS.md). Executable brief: [Prompts.md](../../../Prompts.md) (section M2). Separate from the 10 roadmap phases; roadmap phases stay ML-free.

## Objective
Data acquisition (approved files only). See scope below.

## Scope
- Acquire only the approved list through the Phase 2 pipeline (discover, register, download, validate); resumable, retries, disk checks.
- Fetch approved non-Earthdata sources (inventories, SoilGrids, WorldCover, geology, USGS) with URL, licence, retrieval date, checksum.
- Per-file size, SHA-256, integrity validation, DATASET_LOG entry; data in `data/ml/raw/` or manifest pointers to `data/raw/`.
- `ml/reports/M2_acquisition.md`: arrived, failed, missing vs approved list.

## Out of scope
- Preprocessing, modelling, silent substitution of missing files, anything not on the approved list.

## Gate
none after the M1 approval; stops if sizes or auth deviate from the approved list. The next stage starts only when this stage's acceptance is met and any user stop above is recorded in ML_STATUS.

## Prerequisites
- The user approved the regions and the exact file list (second M1 stop).

## Acceptance (done when)
- Every approved file is present with a verified checksum, or its absence is reported with the reason.
- Manifest completeness, checksum and idempotent re-run tests pass.
- Credentials never printed or logged.

## Implementation status
See ML_STATUS for the real state; record only real test output.

## Constraints
Track rules in Prompts.md and `.claude/rules/ml.md`: all work under `ml/` and `data/ml/`, real data only for performance claims, no unapproved downloads, no leakage, reproducible runs, nothing wired into backend/frontend/API/DB, `PREDICTION_BACKEND` stays `none`.

## Known limitations
Landslide inventories are incomplete and biased toward reported, accessible places; background samples are not proven stable; NISAR temporal depth is verified only in M1; any figure without recorded real output is NOT_VERIFIED.
