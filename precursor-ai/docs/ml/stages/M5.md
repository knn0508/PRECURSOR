## Objective
Exploratory data analysis. See scope below.

## Scope
- Dataset overview, class balance, positives per region and year, coverage maps, missingness.
- Feature-vs-label analysis with effect sizes and multiple-testing caution; InSAR velocity and coherence vs events.
- Spatial analysis (Moran I, clustering, reporting bias) and temporal analysis (seasonality, rainfall and lead-time relationships, non-stationarity).
- Multicollinearity (VIF, correlation clusters), physical sanity checks, artifact and leakage flags.
- Data-sufficiency assessment per planned model family; recommendation of feasible tasks, justified model families and features. Notebooks in `ml/notebooks/`, report `ml/reports/M5_eda.md`.

- **Literature task (user decision 2026-11-15):** before model families are chosen, open and read in full at least 5 more papers (M1 read only 5; items 6-14 in `ml/reports/M1_literature.md` are snippet-only), and update that report.

- **User conditions (2026-11-15):** report the event-date distribution (events cluster in a few winter storms, e.g. 2017) and use a temporal hold-out only if enough separate dates exist in both training and test periods; with ~300-670 events plan tabular baselines first, deep models not justified; consider the Luzon 2023 inventory only as an out-of-region test.

## Out of scope
- Model fitting beyond trivial diagnostics, any peek at the hold-out sets.
