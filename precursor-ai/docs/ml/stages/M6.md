# ML stage M6: Feature engineering, selection and final splits

Status: **NOT_STARTED**. Track: [ADR-0009](../../adr/ADR-0009-ml-development-track.md); status table: [ML_STATUS](../ML_STATUS.md). Executable brief: [Prompts.md](../../../Prompts.md) (section M6). Separate from the 10 roadmap phases; roadmap phases stay ML-free.

## Objective
Feature engineering, selection and final splits. See scope below.

## Scope
- Features justified by EDA and physical reasoning, reusing Phase 5 extractors where they fit; versioned schema with units, source, window, lineage.
- Documented categorical encoding without target leakage.
- Feature selection on train only (collinearity pruning, permutation importance, fold stability); full and reduced variants.
- Final splits: spatial-block CV with buffer gap, temporal hold-out, spatial hold-out region if several regions; split indices hashed.
- Model-ready Parquet/NumPy in `data/ml/splits/` with manifests and a `ModelInputSpec` per variant built with the existing class; `ml/reports/M6_features_splits.md`.

- **User conditions (2026-11-15):** start from the sealed provisional hold-out `data/ml/splits/m5_provisional_holdout_v1`; move the label weight of events in excluded cells onto non-excluded cells inside their accuracy circle (events with no such cell are reported and left out of the primary training set only; keep a sensitivity run with them as they are); the positive-cell definition is decided here; feature sets and the treatment of reporting-bias proxies follow the user's M5 decision.
- **User decisions at the M5 stop (2026-11-15):** susceptibility only; approved models: class-prior, few-feature baseline, regularised logistic regression, shallow RF and gradient boosting (no deep models, InSAR or calibrated probabilities); outputs are relative rankings, never probabilities or warnings.
  - **Feature sets:** A (physical; excludes built-up share, soil cover, water share, coastal lithology; fault distance only in a separate ablation), B (diagnostic, includes reporting proxies, never a susceptibility result), A-matched (Set A with background matched to the event built-up distribution, stratified by built-up quintile). Compare A vs A-matched.
  - **Success criterion:** useful only if it beats the class-prior and few-feature baselines on the SEALED spatial hold-out with confidence intervals excluding no-skill; "not supported by these labels" is an acceptable outcome.
  - **Compute cap:** CPU only, at most 10 CPU-hours total, 2 h wall, 0 GPU-hours; stop and ask if exceeded.
  - **Re-seal rule:** if a new label source is adopted, keep the 50 km blocks and assign the new events to the same blocks BEFORE exploring them; held-out blocks stay held out.
  - **Footprint gap:** re-derive the cell gap from cell footprints (at least 10 km plus one cell diagonal) before any model sees a split.
  - **Blocked** on the label-source decision ([M5b proposal](../../../ml/reports/M5b_label_source_proposal.md)).
