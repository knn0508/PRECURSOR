# ML stage M1: Problem definition, dataset discovery and feasibility

Status: **IN_PROGRESS** (reports done 2026-11-15, awaiting approval). Track: [ADR-0009](../../adr/ADR-0009-ml-development-track.md); status table: [ML_STATUS](../ML_STATUS.md). Executable brief: [Prompts.md](../../../Prompts.md) (section M1). Separate from the 10 roadmap phases; roadmap phases stay ML-free.

## Objective
Problem definition, dataset discovery and feasibility. See scope below.

## Scope
- Problem definition: susceptibility task (static, per cell) and trigger task (dynamic, per cell and time, horizon H); labels, metrics (PR-AUC, recall at fixed false-alarm rate, Brier, calibration), splits, baselines.
- Literature review `ml/reports/M1_literature.md`: at least 10 papers actually opened (DOI, data, metrics, validation method, limits; ABSTRACT_ONLY when full text is unreachable; no invented citations).
- Feasibility `ml/reports/M1_feasibility.md` from real anonymous catalog queries (no login, no download): NISAR products, real date range, coverage, sizes; temporal compatibility of every candidate label source (GLC ends 2016-03-07, COOLR, regional inventories) with the SAR data period; alternatives (Sentinel-1, OPERA, EGMS, ALOS-2) and non-SAR factors.
- 2-3 ranked study designs with regions, expected positives, class balance, size, disk, compute, risks, recommendation.
- Download proposal (names, counts, sizes, AOI, date range, total GB, time).

## Out of scope
- Any download or Earthdata login, preprocessing, modelling.
