## User decisions at the M5 stop (2026-11-15, user, in writing)
1. **Task:** susceptibility only. The trigger task is deferred, not deleted.
2. **Models approved:** class-prior baseline, few-feature baseline, regularised logistic regression, shallow regularised random forest and gradient boosting (XGBoost or LightGBM). **Not approved:** deep models, InSAR, calibrated probabilities. Outputs are relative susceptibility rankings for research, never probabilities or warnings.
3. **Feature sets:** **A** (physical; excludes built-up share, soil cover, water share, coastal lithology; fault distance is NOT in A, separate ablation only). **B** (diagnostic, with reporting proxies; only to show inflation; never a susceptibility result). **A-matched** = Set A with bias-matched background (same built-up distribution as the events, stratified by built-up quintile); compare A vs A-matched. **Success criterion:** useful only if it beats the class-prior and few-feature baselines on the SEALED spatial hold-out with confidence intervals excluding no-skill. "Not supported by these labels" is an acceptable M7/M8 outcome.
