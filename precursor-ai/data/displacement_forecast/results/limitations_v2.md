# Limitations (skill v2)

1. **Single site, single geometry, repeated test inspection.** One OPERA frame (F16940, ascending), one AOI. The 2024+ test period has now been inspected in several rounds (earlier artifact, step 3 ablation, this run). Every test number here is exploratory. A final claim needs a fresh held-out site, time window or geometry (for example F18904 descending).
2. **Ground truth is itself noisy.** Under the white-noise level model, only ~15–20 % of 12-day increment variance is motion (`antipersistence_diagnosis.md`, implied σe 2.3–3.2 mm). 12-day MAE mostly scores noise reversal, which is why B0 wins MAE while getting long-term direction wrong.
3. **The landslide core is unobservable in 2024–2025.** 1 963 px: 6.8 % observed, 91.9 % masked-but-finite (CC = 0, low coherence), 1.3 % missing. Masked values are not labels. Only 761 test samples (0.25 %) fall in the core and 26.5 % of core 144-day windows are scorable. No method here measures or validates the 2024 acceleration.
4. **Derived 144-day target ≠ independent truth.** It is a Huber slope fit to future OPERA observations and inherits OPERA's noise, masking and decorrelation bias. Fits with |slope| ≤ 2 SE are excluded from sign accuracy.
5. **Empirical troposphere correction is not physically validated.** It is applied to every stack used here. OPERA TROPO-ZENITH, GACOS and GNSS checks were not run (new downloads).
6. **Kalman model assumptions.** White level noise, constant-velocity plus random-walk acceleration, global (R, q) for all pixels, no seasonal term, no ministack-boundary noise model. The test-period ACF shows alternating lag-2/3/4 structure (±0.08–0.13) that the model does not capture.
7. **Direction metric granularity.** Per-pixel direction uses 399 moving pixels (spatially correlated, so the effective sample is smaller than 399 even with cluster bootstrap). Sample-level direction on high-signal labels (|y| > 1 σ_noise) measures something different (next-measurement sign) and favours B0.
8. **Not done:** the sign-aware auxiliary loss (skill Step 3.5), recency-weighted slopes, seasonal state components, a rolling causal conformal update, and any cross-sensor value comparison (blocked: no time overlap and NISAR sign not documented in the file).
9. **Reproducibility tolerance.** GPU (cuDNN) kernels are not bit-deterministic. B0 reproduces to 2.4514 / 3.0136 (artifact 2.451 / 3.014); notebook E3 was 2.4535 ± 0.0106. T1 is 2.817 with min_n = 6 (Step 0) vs 2.814 with min_n = 12 (Step 2): a different abstention rule, documented in each table. The core size difference (1 958 earlier vs 1 963 now) is not reconciled; 1 963 under the current stack is frozen.
